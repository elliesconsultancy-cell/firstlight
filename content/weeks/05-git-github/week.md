So far your websites have lived only on your own computer. This week, that changes. By the end of it, you will have a real web address that you can send to friends, family or a future employer.

To get there, you will learn three tools that every developer uses every day. The **terminal** lets you talk to your computer by typing commands. **Git** saves snapshots of your work, so you can always go back if something breaks. **GitHub** is a website that stores your Git projects online, lets you work with other people, and can even host your website for free with **GitHub Pages**.

These tools can feel strange at first, especially the terminal. That is completely normal. Every developer once typed their first command and wondered if they had broken something. You will type the same few commands again and again, and soon they will feel natural.

Keep a notebook (paper or digital) of the commands you learn this week. It will be very useful later.

## By the end of this week you will be able to

- Move around folders in the terminal with `pwd`, `ls`, `cd` and `mkdir`
- Explain what version control is and why it is useful
- Track changes with `git init`, `git status`, `git add`, `git commit` and `git log`
- Create a repository on GitHub, push your work to it, and clone it
- Describe branches and pull requests in simple terms
- Publish a website with GitHub Pages
