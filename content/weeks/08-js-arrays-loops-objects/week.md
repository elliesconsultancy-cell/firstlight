So far, each of your variables has held one value: one name, one price, one score. But real apps deal with *lots* of information. A shopping basket has many items. A class has many students. A library has thousands of books, and each book has a title, an author, a year and more.

This week you'll learn how JavaScript stores collections of information. **Arrays** are ordered lists, like a numbered shopping list. **Objects** are records that group related details together with labels, like a contact card in your phone. Put them together and you can describe almost any real-world data.

You'll also learn **loops**, which let the computer repeat a job for every item in a list. Computers never get bored, so a loop over 5 items or 5 million items is the same amount of code for you to write.

Finally, you'll meet some powerful array methods, `map`, `filter`, `find`, `forEach` and `reduce`, which professional developers use every day to answer questions about data.

## By the end of this week you will be able to

- Create arrays, read items by index, and add or remove items
- Use `for`, `for...of` and `while` loops, and choose the right one for a task
- Create objects and read their values with dot and bracket notation
- Work with arrays of objects, like a list of books or students
- Use `map`, `filter`, `find`, `forEach` and `reduce` to transform and summarise data
