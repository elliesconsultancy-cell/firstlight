## What you'll build

Your very first web page: an **About Me** page. It tells visitors who you are, what you like, and why you're learning to code. It doesn't need to look fancy (we haven't learned CSS yet!). What matters is clean, correct HTML.

## Requirements

- [ ] The file is called `index.html` and lives in a folder called `about-me`
- [ ] It uses the full HTML boilerplate (`<!DOCTYPE html>`, `<html lang="en">`, `<head>`, `<body>`)
- [ ] The `<title>` contains your name
- [ ] There is one `<h1>` heading with your name or a greeting
- [ ] There are at least two `<p>` paragraphs about you
- [ ] There is at least one list (`<ul>` or `<ol>`) with three or more items
- [ ] There is at least one image (`<img>`) with a helpful `alt` description
- [ ] There is at least one link (`<a>`) to another website
- [ ] Every element that needs a closing tag has one
- [ ] Your code is indented so it's easy to read

## Steps/hints

1. In your `firstlight/week-01` folder, create a folder called `about-me`. Inside it create `index.html` and a folder called `images`.
2. Start with the boilerplate. In VS Code you can type `!` then press **Tab**.
3. Plan your content first, in plain words. For example:
   - A greeting with your name
   - Where you're from (as much as you're happy to share)
   - Why you're learning to code
   - A list of hobbies, favourite foods, or goals for this course
   - A picture (you, your town, your pet, or something you love)
   - A link to a website you find useful or interesting
4. Now add HTML tags around your content.
5. For the image, you can:
   - put a photo in your `images` folder and use `src="images/your-photo.jpg"`, **or**
   - use an online image URL, like `https://picsum.photos/400/300`
6. Save often, and refresh the browser to check your work.
7. Open DevTools (`F12` → **Elements**) and check that the structure looks like you expect.

> 💡 **Tip:** If something looks wrong, read your code out loud to your "rubber duck", tag by tag. Check that every `<p>` has a `</p>`, every `<li>` is inside a `<ul>` or `<ol>`, and your image path is spelled exactly right.

> ⚠️ **Watch out:** Only share personal information you're comfortable with. You don't need to include your full name, address, or a photo of yourself. A photo of something you like is perfectly fine.

## How to submit

You have two options. Use the submit form on this page:

- **Option A – Upload your file:** upload your `index.html`. If you used a photo from your computer, upload the image file too.
- **Option B – Share a CodePen link:** go to codepen.io, create a free account, click **Pen**, and paste only the part **inside** your `<body>` into the HTML box. Save it and paste the link into the link box. (Online image URLs work best on CodePen.)

In the written answer box, add one or two sentences: what was easiest, and what was hardest?

## Stretch goals

- Add a second page, `hobbies.html`, in the same folder. Link to it from `index.html`, and link back from `hobbies.html` to `index.html` using relative paths.
- Use both a `<ul>` and an `<ol>` on your page, each where it makes sense.
- Use `<strong>` and `<em>` in your paragraphs to highlight important words.
- Add an HTML comment (`<!-- like this -->`) above each section explaining what it is.
