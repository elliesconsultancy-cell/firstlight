---
title: How the web works
summary: Discover what really happens when you visit a website, and build your very first web page in HTML.
---
You use the web every day: to read the news, send messages, shop and watch videos. But what actually happens between typing an address and seeing a page? This week we lift the lid and look inside.

First, we will learn the difference between the **internet** and the **web** (they are not the same thing!). Then we will follow a web page on its journey from a computer far away, called a **server**, to the browser on your screen.

After that we will get practical. You will learn how files and folders work, and how to describe where a file lives using a **file path**. This sounds small, but it is the cause of many beginner bugs, so it is worth learning well.

Finally, you will write your first real HTML page from scratch and open it in your browser. By the end of the week, you will have a web page about **you**.

## By the end of this week you will be able to

- Explain the difference between the internet and the web
- Describe what browsers, servers, URLs and HTTP requests and responses do
- Write relative file paths to link files in different folders
- Explain what tags, elements and attributes are in HTML
- Write a complete HTML page using the standard boilerplate and open it in a browser
