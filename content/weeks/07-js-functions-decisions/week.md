---
title: Functions, decisions and debugging
summary: Package your code into reusable functions, teach your programs to make decisions, and learn calm, practical ways to find and fix bugs.
---
Last week, every program you wrote ran from top to bottom, once, the same way every time. That's useful, but real programs need more. They need to do the same job many times with different information, and they need to choose what to do depending on the situation.

This week you'll learn the two tools that make this possible. **Functions** let you wrap up a job and give it a name, so you can use it again and again, like a recipe card you can pull out whenever you need it. **Conditions** (`if` and `else`) let your program make decisions, like a sat nav choosing a different route when a road is closed.

You'll also learn one of the most valuable skills in programming: **debugging**. Your code will break. Everybody's code breaks, every day. The difference between a beginner and an experienced developer is not that the experienced developer makes fewer mistakes. It's that they have a calm routine for finding them.

## By the end of this week you will be able to

- Write and call functions that take parameters and return values
- Explain the difference between `return` and `console.log`
- Compare values with `===`, `<`, `>` and friends, and combine conditions with `&&`, `||` and `!`
- Use `if`, `else if` and `else` to make your code choose between options
- Read an error message and say what type of error it is and which line caused it
- Debug code with `console.log` and breakpoints in Chrome DevTools
