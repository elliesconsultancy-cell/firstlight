So far you have built web pages with HTML and made them look good with CSS. HTML is the skeleton of a page and CSS is the clothing. This week we meet the third member of the team: **JavaScript**, the muscles. JavaScript is what makes a page *do* things.

Learning a programming language is a lot like learning a spoken language. At first you learn small words and simple sentences. You make mistakes, and that is normal. Every error message is the computer telling you something useful, not telling you that you are bad at this.

This week we will stay small and careful. You will type JavaScript straight into your browser, store information in variables, do some maths, and work with text. Then you will learn a skill that real developers use every single day: **playing computer**, which means reading code slowly, line by line, and predicting what it will do.

You do not need to install anything new. Chrome and the course playground are enough. If you want, there is an optional section showing how to install Node.js.

## By the end of this week you will be able to

- Explain what JavaScript is and where it runs
- Use the browser console and `console.log` to see what your code is doing
- Recognise the basic types of values: strings, numbers, booleans, `undefined` and `null`
- Create variables with `let` and `const`, and choose clear names for them
- Combine values with operators and build text with template literals
- Trace a short program line by line and predict its output
