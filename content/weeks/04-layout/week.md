title: Layout & responsive design
summary: Arrange boxes on the page with Flexbox and Grid, and make your sites look good on phones and big screens alike.
---
Last week you learned that every element is a box. This week you will learn how to **arrange** those boxes: side by side, in rows and columns, centred, spread out, or stacked.

We start with how the browser lays things out on its own ("normal flow"). Then we meet two powerful tools: **Flexbox**, which is perfect for lining things up in one direction (like a navigation bar), and **CSS Grid**, which is perfect for rows *and* columns (like a gallery of cards).

Finally, we tackle **responsive design**. More than half of all web visits happen on phones, so your pages need to work on a small screen as well as a large one. You will learn to design for mobile first and then add changes for bigger screens with media queries.

This week has a lot of "aha" moments. Keep DevTools open, resize your browser often, and play the two layout games linked in the lessons.

## By the end of this week you will be able to

- Explain normal flow and the difference between block and inline elements
- Use Flexbox to build a navigation bar and align items in a row or column
- Use CSS Grid to build a gallery of cards with `fr`, `repeat()` and `gap`
- Add the viewport meta tag and make images fit their containers
- Write mobile-first CSS with media queries
- Build a landing page that works on both mobile and desktop
