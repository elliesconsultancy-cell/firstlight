Last week you wrote your first web page. This week you learn to write HTML **well**. Good HTML is clear for other developers. It helps search engines. And everyone can use it, including people who use a screen reader or a keyboard instead of a mouse.

We start with **semantic HTML**. This means choosing tags that say what your content means, like `<header>`, `<nav>`, `<main>` and `<footer>`. Then we go deeper into links, images, lists and tables.

Next are **forms**. Forms are how websites collect information: sign-ups, searches, orders and messages. You learn the different input types, why every input needs a label, and how the browser can check answers for you.

Last, you learn why **accessibility** matters. You also learn to check your own work with the HTML validator and the DevTools Elements panel. Professional developers do this every day.

## By the end of this week you will be able to

- Structure a page with semantic elements and a sensible heading order
- Use links, images (with good alt text), lists and tables correctly
- Build a form with labelled inputs, buttons and validation attributes
- Explain why accessibility matters and apply some basic accessibility checks
- Use the HTML validator and DevTools to find and fix mistakes
