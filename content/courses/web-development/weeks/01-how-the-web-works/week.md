You use the web every day: to read the news, send messages, shop and watch videos. But what happens between typing an address and seeing a page? This week we look inside.

First, you learn the difference between the **internet** and the **web**. They are not the same thing. Then we follow a web page on its journey. It starts on a faraway computer called a **server**. It ends in the browser on your screen.

Next we get practical. You learn how files and folders work. You learn how to say where a file lives, with a **file path**. This looks small, but it causes many beginner bugs. It is worth learning well.

Finally, you write your first real HTML page and open it in your browser. By the end of the week, you will have a web page about **you**.

## By the end of this week you will be able to

- Explain the difference between the internet and the web
- Describe what browsers, servers, URLs and HTTP requests and responses do
- Write relative file paths to link files in different folders
- Explain what tags, elements and attributes are in HTML
- Write a complete HTML page using the standard boilerplate and open it in a browser

## Day plan

### Learning objectives
- Explain the difference between the internet and the web
- Name the parts of a URL and say what a request and response are
- Write relative paths for files in different folders
- Write a full HTML page with the boilerplate and open it in a browser

### Purpose
Learners move from using the web to understanding it, then make their first page. Paths and the boilerplate are used every week after this. Week 2 builds on this page with semantic HTML and forms.

### Agenda
1. **The internet and the web.** Teach roads versus traffic, and client versus server. Learners open View page source on a site.
2. **URLs, requests and responses.** Split a URL, walk through one visit, and teach the four status codes. Open the Network tab together.
3. **Files, folders and file paths.** Draw the folder tree. Teach same folder, subfolder and `..`. Fix a broken image path live.
4. **Your first HTML page.** Teach tags, attributes, lists and the boilerplate. Learners build `first-page.html` and find it in DevTools.
5. **About Me page.** Launch the assignment. Show the folder structure and the submit form. Walk around and check image paths.
