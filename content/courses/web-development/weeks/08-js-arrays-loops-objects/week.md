So far, each variable held one value: one name, one price, one score. But real apps handle *lots* of information. A shopping basket has many items. A class has many students. A library has thousands of books. Each book has a title, an author, a year and more.

This week you learn how JavaScript stores groups of information.

- **Arrays** are ordered lists. Think of a numbered shelf.
- **Objects** are records. They group related details under labels. Think of a contact card in your phone.

Put them together, and you can describe almost any real-world data.

You also learn **loops**. A loop makes the computer repeat a job for every item in a list. A computer does not get bored. A loop over 5 items and a loop over 5 million items need the same code.

Last, you meet five array methods: `map`, `filter`, `find`, `forEach` and `reduce`. Professional developers use them every day to answer questions about data.

## By the end of this week you will be able to

- Create arrays, read items by index, and add or remove items
- Use `for`, `for...of` and `while` loops, and choose the right one for a task
- Create objects and read their values with dot and bracket notation
- Work with arrays of objects, like a list of books or students
- Use `map`, `filter`, `find`, `forEach` and `reduce` to transform and summarise data
