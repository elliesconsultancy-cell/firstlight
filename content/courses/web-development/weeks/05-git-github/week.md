So far your websites live only on your own computer. This week, that changes. At the end, you will have a real web address. You can send it to friends, family or a future employer.

To get there, you learn three tools that developers use every day:

- The **terminal** lets you talk to your computer by typing commands.
- **Git** saves snapshots of your work. If something breaks, you can go back.
- **GitHub** is a website that stores your Git projects online. It lets you work with other people. It can even host your website for free with **GitHub Pages**.

These tools can feel strange at first, especially the terminal. That is normal. Every developer once typed a first command and wondered if they had broken something. You will type the same few commands again and again. Soon they feel natural.

Keep a notebook (paper or digital) of the commands you learn this week. It will help you later.

## By the end of this week you will be able to

- Move around folders in the terminal with `pwd`, `ls`, `cd` and `mkdir`
- Explain what version control is and why it is useful
- Track changes with `git init`, `git status`, `git add`, `git commit` and `git log`
- Create a repository on GitHub, push your work to it, and clone it
- Describe branches and pull requests in plain words
- Publish a website with GitHub Pages

## Day plan

### Learning objectives
- Learners can move around folders with `pwd`, `ls`, `cd` and `mkdir`.
- Learners can track changes with `git init`, `git status`, `git add`, `git commit` and `git log`.
- Learners can push to a GitHub repository and clone one.
- Learners can describe branches and pull requests in plain words.
- Learners can publish a site with GitHub Pages.

### Purpose
Weeks 3 and 4 produced a styled, responsive page that only lives on a laptop. This week it goes online and learners start using the tools of professional work. The Git habits are used in every later week.

### Agenda
1. **Terminal basics.** Teach `pwd`, `ls`, `cd` and `mkdir`, and reassure nervous learners. Learners run the `firstlight-practice` sequence and guess the last `pwd`.
2. **Git and save points.** Teach the edit, add, commit loop and good messages. Learners make three commits in `git-practice` and read `git log --oneline`.
3. **GitHub, pushing, branches and pull requests.** Teach remote, push, clone, then branches and pull requests. Learners push `git-practice` and sort out sign in problems with help.
4. **Publishing with GitHub Pages.** Teach the file checks and the Settings, Pages steps. Learners turn on Pages for `git-practice` and open the live link.
5. **Publish your landing page.** Launch it from their week 4 folder. Check the commit count first, then the push, then the live site on a phone.
