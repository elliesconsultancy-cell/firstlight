So far you have built web pages with HTML and styled them with CSS. HTML is the skeleton of a page. CSS is the clothing. This week we meet the third member of the team: **JavaScript**, the muscles. JavaScript makes a page *do* things.

Learning a programming language is like learning a spoken language. At first you learn small words and short sentences. You make mistakes. That is normal. An error message is the computer giving you useful information. It is not saying you are bad at this.

This week we stay small and careful. You will:

- type JavaScript straight into your browser,
- store information in variables,
- do some maths and work with text.

Then you learn a skill that real developers use every day: **playing computer**. This means reading code slowly, line by line, and saying what it will do.

You do not need to install anything new. Chrome and the course playground are enough. One optional section shows how to install Node.js.

## By the end of this week you will be able to

- Explain what JavaScript is and where it runs
- Use the browser console and `console.log` to see what your code is doing
- Recognise the basic types of values: strings, numbers, booleans, `undefined` and `null`
- Create variables with `let` and `const`, and choose clear names for them
- Combine values with operators and build text with template literals
- Trace a short program line by line and predict its output

## Day plan

### Learning objectives
- Learners can run JavaScript in the console and with `console.log`.
- Learners can store values in variables with `let` and `const`.
- Learners can use operators and string methods to build and change text.
- Learners can trace a short program and predict its output.

### Purpose
This is the first week of JavaScript, after HTML and CSS. It builds the habits (predict, run, explain) that the next two weeks rely on. Week 7 adds functions and decisions.

### Agenda
1. **Meet JavaScript and the console.** Show the three languages, open the console and use `console.log`. Learners type the Ada example and change it.
2. **Values and variables.** Teach types, then `const` and `let` and naming. Learners guess the output of the `firstName` Try it, then change it.
3. **Operators, expressions and strings.** Cover `%`, `"5" + 3`, template literals and slice. Learners run the `rawName` example with their own name.
4. **Playing computer.** Trace apples and pears together with a trace table. Learners trace the `a`, `b`, `c` program on paper.
5. **Console warm-ups.** Launch the starter code and do Exercise 1 together. Learners work through the rest, then write the reflection.
