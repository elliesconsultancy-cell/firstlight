The words you give an AI are called a **prompt**. A good prompt is the cheapest and fastest way to get better results. You do not need code, and you do not need more money. You only need to say what you want clearly.

This week we use one picture: a very keen new **intern**. The intern has read everything, but knows nothing about your business. Your prompt is the set of instructions you give that intern.

First, you will learn what a prompt is and why vague prompts give vague answers. Then you will learn four tools that make prompts better: a role, examples, a format and steps. Finally, you will learn the **system prompt**, the job description that gives BakeBuddy its personality, and how to improve a prompt by testing it.

You will practise in any AI chat. Then you will keep your best prompts in a **prompt notebook**, which we use again in later weeks.

## By the end of this week you will be able to

- Explain what a prompt is, using the intern picture
- Rewrite a vague prompt into a clear one
- Use a role, examples, an output format and steps in a prompt
- Write a system prompt that gives BakeBuddy a personality and rules
- Improve a prompt by testing it, changing one thing at a time

## Day plan

### Learning objectives
- Explain a prompt with the intern picture.
- Rewrite a vague prompt into a clear one.
- Use a role, examples, a format and steps in a prompt.
- Write a system prompt that gives BakeBuddy a personality and rules.
- Improve a prompt by testing it and changing one thing at a time.

### Purpose
Learners now know how a model works (Week 0) and how it reads (Week 1). This week they learn to steer it with words. The system prompt written here is used when they make their first API call in Week 3, and the test list grows into the taste test in Week 7.

### Agenda
1. **What is a prompt?** Teach the intern picture and show Prompt A against Prompt B. Learners try the vague and better prompts in a chat.
2. **Better prompts.** Teach the four tools: role, examples, format, steps. Learners rewrite the vegan bread prompt.
3. **System prompts and iteration.** Teach the job description, the write-test-look-change-one-thing loop and the test list. Learners write a system prompt and five tests for their own idea.
4. **Prompt notebook.** Launch with a live demo of one test. Check that each learner has a test list with a sneaky message and changes only one thing.
