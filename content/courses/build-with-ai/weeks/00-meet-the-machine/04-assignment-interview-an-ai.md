## What you'll build

A short **interview report**. You will chat with any AI assistant and run five small tests on it. For each test, you write what you asked, what it answered, and what you think. No code is needed.

This report is the start of your own notes about AI. You will use it again when we build BakeBuddy.

> ⚠️ **Watch out:** Do not type passwords, secret keys, or other people's private details into any AI chat. Use made-up examples only.

## Requirements

- [ ] You name the AI you used (for example Claude or ChatGPT) and the date
- [ ] Test 1, a writing task: you ask for a short friendly notice for a bakery and judge its quality
- [ ] Test 2, a fact you know: you ask a question where you know the true answer, and say if it was right
- [ ] Test 3, a thing that does not exist: you ask about an invented book, person or place, and say what it did
- [ ] Test 4, a counting or maths task: for example "How many letter e are in the word 'excellence'?" and you check the answer yourself
- [ ] Test 5, a private fact: you ask something only you know (like "What did I eat for breakfast?") and note how it reacted
- [ ] For each test you write: the question, the answer (short copy is fine), and one sentence of your opinion
- [ ] At the end, you list 2 things the AI did well and 2 things it did badly
- [ ] You write one sentence on how you would check its answers in future

## Steps/hints

1. Open an AI chat. Start a new conversation for the interview.
2. Write down the name of the AI and today's date.
3. Run the five tests one by one. Copy each question and a short part of the answer into your notes.
4. For test 4, count the letters yourself first, so you can compare.
5. For tests 2 and 3, check the answer using a trusted website or book.
6. If an answer surprises you, try asking the same question again in a new chat. Did you get the same answer? Write down what you notice.
7. Read your notes. Write the final "good and bad" lists and the one-sentence checking habit.

> 💡 **Tip:** There are no wrong results here. If the AI got everything right, that is information too. Try making the test a little harder and write down what happens.

## Stretch goals

- Ask the same question three times in separate chats. Compare the answers. Why might they differ? (A hint: Week 1 explains this.)
- Ask the AI: "How sure are you about that answer, from 1 to 10?" Does the number match what you found?
- Try the same five tests on a second AI and compare.

## Instructor agenda

### Learning objectives
- Run five small tests on a real AI and record the results.
- Judge the answers honestly, including checking facts and counts themselves.
- Write down a personal habit for checking AI answers.

### Purpose
Learners see the strengths and weak spots first-hand, which lasts longer than reading about them. The report also becomes the start of their own AI notes.

### Things to do
1. Launch it: ask learners to open any AI chat they like, in a new conversation. Remind them to use made-up examples only. No passwords, no private details.
2. Demonstrate one test live, ideally test 4: count the letter e in "excellence" yourself first, then ask the AI and compare. Show that you write the question, a short copy of the answer, and one sentence of opinion.
3. Show the submission shape from the page, so learners know the report layout before they start.
4. Point out that there are no wrong results. If the AI got everything right, they should make a test harder.

### What good work looks like
- The AI name and date are at the top.
- All five tests are there (writing, known fact, invented thing, counting or maths, private fact), each with the question, a short answer and one opinion sentence.
- Test 4 shows that the learner counted themselves and compared.
- There are two good things and two bad things listed, and they match what the tests showed.
- There is one sentence on how they will check answers in future.

### Watch for
- Learners copy the whole long answer instead of a short part. Ask for short copies.
- Learners accept the answer to test 3 without checking the invented thing really does not exist. Ask: how do you know?
- Someone types real private details for test 5. Remind them to use made-up or harmless examples.
